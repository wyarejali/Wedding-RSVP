# Wedding RSVP Plugin

## Description

The Wedding RSVP plugin allows users to submit their RSVP for a wedding event. It features an AJAX-enabled form for submissions, which hides the form and displays a success message upon submission. The plugin also manages submissions in a list table with options to edit, delete, and download submission information as an Excel file.

## Features

-   AJAX-enabled RSVP form
-   Manage submissions in a list table
-   View submission details
-   Options to edit, delete, and download submission information
-   Scalable and organized code structure

## Installation

1. Upload the `wedding-rsvp` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Use the shortcode `[wedding_rsvp_form]` to display the RSVP form on any page or post.

## Usage

-   After activation, navigate to the RSVP form page to submit your details.
-   Admins can view submissions in the WordPress admin area under the "Wedding RSVP" menu.
